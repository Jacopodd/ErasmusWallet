#ErasmusWallet

ErasmusWallet è un’app mobile pensata per aiutare studenti Erasmus e viaggiatori a gestire il proprio budget in modo semplice, moderno e intelligente.

L’app permette di monitorare:
- wallet e carte
- entrate e spese
- saldo disponibile
- simulazioni di budget
- proiezioni economiche durante il periodo Erasmus

Il design è basato su una UI moderna in dark mode con stile liquid glass.

---

# Features

## Wallet multipli
- Gestione di contanti e carte
- Aggiunta dinamica di nuovi wallet
- Saldo iniziale personalizzabile per ogni wallet

## Gestione movimenti
- Entrate e spese modificabili
- Calcolo automatico dei totali
- Aggiornamento realtime del budget

## Simulazioni
Tre modalità di previsione:
- Prudente
- Realistico
- Ottimistico

## Dashboard avanzata
- Panoramica completa del budget
- Card responsive
- Layout moderno e professionale

## UI moderna
- Dark mode permanente
- Stile glassmorphism / liquid glass
- Palette cyan / blu / viola
- Animazioni e glow moderni

# Installazione

## Requisiti
- Android Studio
- JDK 17+
- Android SDK aggiornato

## Setup

```bash
git clone https://github.com/Jacopodd/ErasmusWallet.git
cd ErasmusWallet
```

Apri il progetto con Android Studio ed esegui la build.

---

# Build

## Debug

```bash
./gradlew assembleDebug
```

## Release

```bash
./gradlew assembleRelease
```
